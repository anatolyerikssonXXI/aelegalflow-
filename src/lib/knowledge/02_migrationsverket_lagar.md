# Migrationsverket — Lagar, förordningar och EU-regelverk

## Centrala svenska lagar

| Lag | Innehåll |
|-----|---------|
| **Utlänningslagen (2005:716)** | Grundlagen för utlänningars inresa, vistelse, arbete och skydd i Sverige |
| **Utlänningsförordningen (2006:97)** | Tillämpningsregler: resehandlingar, viseringar, uppehållstillstånd, verkställighet |
| **Lag om mottagande av asylsökande (1994:137)** | Sysselsättning och bistånd till asylsökande |
| **Lag om mottagande av nyanlända (2016:38)** | Kommunalt mottagande av nyanlända |
| **Lag om hälso- och sjukvård åt asylsökande (2008:344)** | Regionernas skyldighet att ge vård |
| **Lag om god man för ensamkommande barn (2005:429)** | God man för ensamkommande minderåriga |
| **Lag om svenskt medborgarskap (2001:82)** | Ansökan och beviljande av medborgarskap |
| **Lag om särskild kontroll av vissa utlänningar (2022:700)** | Säkerhetskontroll av utlänningar |
| **Förvaltningslagen (2017:900)** | Myndigheters ärendehandläggning, gäller fr.o.m. 1 juli 2018 |
| **Offentlighets- och sekretesslagen (2009:400)** | Allmänna handlingar, sekretess, handlingsoffentlighet |
| **Utlänningsdatalagen (2016:27)** | Personuppgiftsbehandling inom migrationsområdet |

## Internationella konventioner

| Konvention | Innehåll |
|-----------|---------|
| **1951 års flyktingkonvention** | Definierar flyktingstatus och rättigheter (se separat fil) |
| **1967 års tilläggsprotokoll** | Avskaffade tidsbegränsningar i flyktingkonventionen |
| **EKMR (Europakonventionen om mänskliga rättigheter)** | Grundläggande rättigheter, ECHR-domstolen i Strasbourg |
| **FN:s barnkonvention** | Barns rättigheter, gäller som svensk lag fr.o.m. 2020 |
| **1954 New York-konventionen** | Statslösas rättsliga ställning |

## Försörjningskrav 2026

- Arbetstillstånd: minst **29 680 kr/mån** (80% av medianlönen per juni 2025)
- Familjeåterförening vuxen: minst **6 243 kr/mån** efter skatt och hyra
- Per barn (beroende på ålder): **3 336–5 339 kr/mån** tillägg
